# Статус поставки 1.0.0

Рабочее ядро по разрешённому в §104 приоритету первой версии. Эта поставка **не заявляет полное выполнение всех 106 разделов**. Таблица отмечает реализованные функции и оставшиеся границы; «реализовано» не означает доказательство всех возможных сочетаний правил.

Проверки: 39/39 тестов ядра; 27/27 этапов браузерной проверки, Chromium 145. Вёрстка проверена на ширинах 320/390/768/1280. Офлайн-перезагрузка и standalone file:// прошли. Отдельно пройдено полное закрытие браузера и запуск без сети с сохранённым персонажем. Результаты — в tests/.

## Известные ограничения точности

Сложные и условные формулы заклинаний, несколько независимых попаданий, выбор типа урона, завершение ярости по событиям хода, ауры на других существах, полноценный Wild Shape и большинство редких подклассовых взаимодействий не автоматизированы. Игрок использует текст, отдельные броски, ресурсы и эффекты. Магические бонусы предметов не извлекаются из описания сами.

Миграция v3 сохраняет исходник, но требует проверки книги заклинаний и сохранённой коррекции максимума HP. Данные не удаляются при миграции.

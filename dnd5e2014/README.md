Offline mobile-first PWA for D&D 5e (2014 rules).

- Data-driven race/subrace + Basic Rules background creator
- Fighter, Wizard, Cleric levels 1–5
- Barbarian, Rogue, Monk, Paladin and Ranger level 1
- Barbarian Rage and Unarmored Defense
- Rogue Expertise + Sneak Attack reference
- Monk Unarmored Defense + Martial Arts d4

- Ranger Favored Enemy and Natural Explorer choices
- Race ability bonuses, speed, supported resistances and racial skills
- Background skill replacement and Custom Background skills
- Spellcasting, concentration, rests, death saves, autosave, Undo and offline PWA

# D&D 5e 2014 Player — Core v4.5

Offline mobile-first PWA for D&D 5e (2014 rules).

## Core v4.5
- Class-specific starting equipment packages for all twelve classes
- Weapons, armor, ammunition, packs, foci, holy symbols, spellbook and thieves’ tools are added to inventory
- The selected equipment package is stored with the character and validated during creation
- Live Review & Validation card in Character Creator
- Review shows final racial ability scores, race/class/background, class skills and starting equipment
- Create Character is disabled while required choices are invalid
- Existing v1–v4 characters remain compatible

## Existing systems retained
All twelve classes at creation; Fighter/Wizard/Cleric 1–5; other classes level 1; race/background creator; spellcasting; concentration; combat; rests; death saves; autosave; Undo; import/export; offline PWA.

## Next
Expand level progression for the remaining nine classes, then add multiclass rules.

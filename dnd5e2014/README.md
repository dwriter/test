# D&D 5e 2014 Player — Core v4.4

Offline mobile-first PWA for D&D 5e (2014 rules).

## Core v4.4
- All twelve 2014 classes are available in Character Creator
- Fighter, Wizard and Cleric levels 1–5
- Barbarian, Rogue, Monk, Paladin, Ranger, Bard, Druid, Sorcerer and Warlock level 1
- Bardic Inspiration d6 with Charisma-based uses
- Druid prepared spellcasting and Druidic
- Sorcerer Draconic Bloodline with Draconic Resilience (+1 HP, AC 13 + DEX unarmored)
- Warlock Fiend patron and Pact Magic; Pact slot returns on Short or Long Rest
- Known-spell vs prepared-spell workflows
- Expanded curated SRD spell set for Bard/Druid/Sorcerer/Warlock
- Existing race/background creator, combat, rests, concentration, death saves, autosave, Undo and offline PWA

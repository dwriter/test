# Тихая мастерская — практикум чтения

Небольшой автономный веб-практикум для возвращения к чтению художественной литературы как к отдельному хобби. **Аудиокниги не исключаются**: обе формы фиксируются и сравниваются по субъективным оценкам вовлечённости, понимания и удовольствия.

## Открыть

После публикации GitHub Pages: **https://dwriter.github.io/test/reading-atelier/**

Проект находится в папке `reading-atelier/` общего репозитория `dwriter/test` и **не затрагивает остальные приложения**.

## Что есть

- Маршрут: *Солярис* → *Война с саламандрами* → *Левая рука тьмы* → *Ложная слепота*. Порядок свободный, можно добавить собственные книги.
- Выбор текущей книги, статус «в планах / читаю / на паузе / прочитано», текущая и общая страница издания.
- Нежный план на неделю (старт: четыре встречи по 8–15 минут); минуты можно менять по дням.
- Таймер на 5 / 8 / 12 / 20 минут и ручной журнал чтения/аудио.
- Учёт минут и страниц, оценка состояния, вовлечённости, понимания и удовольствия (1–5).
- Шаблон заметок по главе, вопросы для обсуждения, еженедельный обзор.
- Напоминания о незавершённых книгах внутри приложения, пауза на 7 дней и скачивание разового `.ics`-события для календаря.
- Советы по чтению дома (кресло-качалка, компьютерное кресло) и в электричке.
- JSON-экспорт и импорт записей; работает офлайн после первичной загрузки благодаря service worker.

## Важно

Всё хранится локально в браузере (`localStorage`), без аккаунта и сервера. **Данные не синхронизируются между устройствами автоматически.** Используйте «Сохранить данные», чтобы создать резервную копию или перенести записи на другой телефон. Очистка данных сайта удалит локальные записи, если нет копии.

Напоминания **не отправляются в фоне**: они видны при открытии приложения. Файл `.ics` можно импортировать в календарь для внешнего напоминания. Таймер также работает только пока страница открыта. Оценки чтения и аудио — наблюдения о вашем собственном опыте, не строгий научный эксперимент.

## Запуск локально

Откройте `index.html` (без сборки) либо запустите простой сервер, например `python -m http.server 8000` в этой папке. Сервис-воркер включится на HTTPS при публикации GitHub Pages.

## Технологии

HTML + CSS + JavaScript. Без фреймворков, сборщиков, внешних API и серверного хранения. Подключение Google Fonts необязательно: предусмотрены системные запасные шрифты.

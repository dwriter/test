# Тихий прогресс 2.0

Лёгкое автономное приложение-календарь для контроля питания и веса. Работает на смартфоне и компьютере, без регистрации.

## Новое в версии 2.0

- **Быстрая отметка за сегодня** в верхней части экрана с отменой последнего действия.
- **Соблюдение и заполненность отдельно:** соблюдение = «по плану» / отмеченные дни; заполненность = отмеченные дни / прошедшие дни месяца (для завершённых месяцев — все дни).
- **Главный экран с текущим весом, целью и прогрессом**, полученными из ваших записей.
- **Тренд веса:** пунктир на графике — простая скользящая средняя по последним трём взвешиваниям. Сравнение «около четырёх недель» показывается только при наличии записи с интервалом от 21 до 35 дней относительно последнего взвешивания. Тренд носит информационный характер, не является прогнозом.
- **Недельный обзор:** отметки за текущую или выбранную прошлую неделю, заполненность недели и сравнение с предыдущей неделей, если есть данные.
- **Промежуточные цели** шагами по 5 кг, если заданы вес и цель.
- **CSV для Excel** и прежние экспорт/импорт JSON для резервных копий.

## Использование

Откройте страницу [GitHub Pages](https://dwriter.github.io/test/weight-calendar/) на смартфоне. В Chrome выберите «Установить приложение» либо «Добавить на главный экран».

Нажимайте «По плану» или «Не по плану» каждый день; отметка сохранится сразу. Выбирайте даты в календаре, чтобы редактировать прошлые записи. Раз в неделю добавляйте вес. В настройках можно поменять целевой вес.

Пустые дни не считаются ни успешными, ни неуспешными. Для анализа веса старайтесь взвешиваться в сопоставимых условиях.

## Важное о данных

Используется прежний ключ `localStorage`: `quiet-progress-v1`. **Обновление кода не удаляет и не заменяет старые записи**. Данные остаются только в браузере конкретного устройства, не передаются в репозиторий GitHub и не синхронизируются. Для переноса между устройствами используйте JSON-файл: «Скачать копию» → «Восстановить». Очистка данных сайта может удалить историю.

CSV предназначен для просмотра и анализа в Excel; для восстановления в приложение нужен JSON.

Приложение работает без внешних библиотек; после первоначальной загрузки оболочка доступна офлайн через service worker. Для установки как PWA нужен HTTPS (GitHub Pages уже предоставляет его).

# Котлеты на неделю

Приложение со списками покупок на 7 дней по трём рецептам: курица, индейка, говядина. Сохраняет галочки, цену каждой закупки с датой, стоимость одного дня и историю расходов. Есть резервная копия JSON и импорт.

Открыть: https://dwriter.github.io/test/kotlety-week/

Важно: история хранится в localStorage на устройстве, а не в GitHub. Удаление данных браузера удаляет историю, если не сделана резервная копия.

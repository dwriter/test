# Учёт часов — PWA v9

Версия с несколькими учебными годами, шаблоном рабочей недели, графиком накопленного дохода и закрытием месяцев.

## Обновление уже опубликованного приложения на GitHub Pages
1. В репозитории откройте **Code**.
2. Загрузите с заменой файлы `index.html`, `manifest.json`, `service-worker.js`, `icon-192.png`, `icon-512.png`.
3. GitHub Pages уже настраивать заново не нужно.
4. Подождите 1–3 минуты, откройте сайт и обновите страницу. Установленное PWA получит новую версию после обновления/повторного запуска.

## Данные
- Приложение использует тот же локальный ключ хранения, что и предыдущая версия, поэтому существующие данные 2026/27 мигрируют автоматически.
- Старые JSON-копии также можно импортировать: они будут преобразованы в формат с несколькими учебными годами.
- Перед заменой файлов всё равно рекомендуется скачать JSON-копию.

## Новые функции
- **Обычная рабочая неделя:** в настройках задаются типичные часы по каждому дню недели; в карточке дня есть кнопка «Как обычно».
- **График:** во вкладке «Месяц» показан накопленный доход по дням.
- **Закрыть месяц:** защищает месяц от случайного изменения; его можно разблокировать.
- **Несколько учебных лет:** переключатель года находится вверху приложения; в настройках можно создать следующий учебный год.

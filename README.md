# Учёт часов — PWA

Готовое офлайн-приложение для учебного года 2026/27.

## Файлы
- `index.html` — приложение.
- `manifest.json` — параметры установки PWA.
- `service-worker.js` — офлайн-кэш.
- `icon-192.png`, `icon-512.png` — иконки.

## Как разместить на GitHub Pages
1. Создайте новый репозиторий на GitHub, например `hours`.
2. Загрузите в корень репозитория **все пять файлов из этой папки**.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Branch: `main`, Folder: `/ (root)`, затем **Save**.
6. GitHub покажет HTTPS-адрес вида `https://ИМЯ.github.io/hours/`.
7. Откройте этот адрес на Android в Chrome.
8. Во вкладке «Настройки» нажмите **«Установить на телефон»**. Если кнопка не вызывает системное окно, используйте меню Chrome → **«Установить приложение»** / **«Добавить на главный экран»**.

## Важно о данных
Часы и настройки хранятся локально на телефоне в хранилище приложения. GitHub получает только код приложения, а не ваши внесённые часы.

Если вы уже меняли данные в предыдущей HTML-версии после её скачивания, сначала сделайте там **«Скачать копию JSON»**, а затем импортируйте этот JSON в установленном PWA.

Для резервной копии данных удобно периодически скачивать JSON и сохранять его на Яндекс Диске.
